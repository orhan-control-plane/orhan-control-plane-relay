# orhan-control-plane-relay

Transport-only repository for the Orhan Control Plane GitHub event transport.

This repository is **not** authoritative for any project state and contains
**no** confidential information. It is deliberately public and content-minimal
so that GitHub Free branch rulesets and workflow execution protections apply.

## Contents

- `.github/workflows/ocp-relay-canary.yml` - an inert, fail-closed workflow
  placeholder that identifies the exact workflow referenced by the
  `ocp-relay-runners` organization runner group access policy.

## Security

See [SECURITY.md](SECURITY.md). No secrets, credentials, project source or
private infrastructure configuration are stored in this repository.
